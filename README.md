# Boss Lab press kit

Boss Lab is a free Android game. Build a boss from 60+ parts, upgrade it, and watch it fight through 100 stages, plus async Arena PvP. Online-only, no forced ads, in-app purchases. The art and audio are AI-assisted.

- Website: https://www.bosslab.xyz/
- Google Play: https://play.google.com/store/apps/details?id=com.bosslab.game&utm_source=github
